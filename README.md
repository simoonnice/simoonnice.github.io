# Md Simoon Nice — Academic Website

Official GitHub Pages source for https://simoonnice.github.io/

## Publish
Create the public repository `simoonnice.github.io` under GitHub user `simoonnice`, then upload **all files and folders from this package to the repository root**.

GitHub Pages should publish the site at:
https://simoonnice.github.io/

## Search indexing
After the site is live:
1. Add `https://simoonnice.github.io/` to Google Search Console.
2. Request indexing for the homepage.
3. Submit `https://simoonnice.github.io/sitemap.xml`.
4. Add the new website URL to ORCID, Google Scholar, ResearchGate, LinkedIn, Scopus/Web of Science profiles where editable.

## Easy updates
- Main text/content: `index.html`
- Design/colors/layout: `css/style.css`
- Images: `images/`
- Search crawler rules: `robots.txt`
- Sitemap: `sitemap.xml`

Keep filenames stable when replacing photos to avoid editing HTML.
